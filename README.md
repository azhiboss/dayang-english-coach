# Dayang English Coach 大洋英语

面向大洋医疗外贸场景的静态英语练习工具。课程、进度、收藏和弱项词保存在本设备浏览器的 IndexedDB；无需账号、后端、外部 API 或构建。保留原有9模块、126条Demo内容，新增605个行业词汇与客户近义表达、3,025个双语例句；每条配5句，按基础、进阶、商务长句递进。本地词典包含2,206条释义，覆盖内置课程英文词项。

## 在电脑本地预览

在终端运行：

```bash
cd dayang-english-coach
python3 -m http.server 8000
```

随后用电脑浏览器打开 [本地预览](http://localhost:8000/)。保持终端运行，按 `Control+C` 停止。不要双击 `index.html` 后通过 `file://` 使用：模块加载、Service Worker 和数据来源规则与正常网站不同。

`http://localhost` 可用于本机 Service Worker 开发。手机打开电脑的 `http://192.168.x.x:8000` 等局域网地址，仅适合查看部分页面；它不是手机上的 localhost，通常不满足安全上下文要求，不能据此验证完整 PWA 离线、安装或麦克风能力。手机完整使用应访问具有有效证书的 HTTPS 地址。依据：[MDN Service Worker](https://developer.mozilla.org/en-US/docs/Web/API/Service_Worker_API)、[MDN安全上下文](https://developer.mozilla.org/en-US/docs/Web/Security/Defenses/Secure_Contexts)。

## iPhone 添加到主屏幕

先将本目录完整发布到 HTTPS 静态站点，再在 iPhone 上操作：

1. 使用 Safari 打开站点的完整地址，等待页面和内置课程加载完成。
2. 点击 Safari 的页面菜单或更多菜单，再选择“分享”；某些工具栏布局可直接点击分享按钮。
3. 在分享列表中选择“添加到主屏幕”。未显示时，可在列表底部的“编辑操作”中添加此操作。
4. 如果出现“作为网页 App 打开”选项，将它打开，然后点击“添加”。
5. 从主屏幕的“大洋英语”图标打开，保持联网并等离线缓存完成，再尝试断网重开。

这些步骤根据 [Apple官方 iPhone 网页App说明](https://support.apple.com/guide/iphone/open-as-web-app-iphea86e5236/27/ios/27)整理；按钮位置与名称可能随系统语言、Safari布局和系统版本变化。添加图标不会让未缓存的页面自动离线可用。本项目没有因此声明已通过真实 iPhone 的安装、麦克风或系统语音实测。

## 离线范围与版本更新

- **先联网完整打开一次。** Service Worker 成功安装并缓存全部运行资源之后，才具备离线打开的基础；从未打开过的地址在首次断网时不能加载。
- 缓存包含HTML、样式、脚本、内置课程、课程格式和本地图标。导入课程、进度与弱项词保存在 IndexedDB，不通过 Service Worker 缓存用户文件。
- 应用入口和作用域内未知导航优先使用已安装版本的 `index.html`；显式打开缓存清单中的 `README.md`、JSON或图标时返回对应文件，不回到应用首页。静态资源优先缓存，仅缓存同源成功响应，不拦截跨源请求。
- 更新会先安装到等待状态，不自动替换正在使用的版本。点击“更新并重新打开”后才发送 `SKIP_WAITING`；切换并重新载入页面后使用新版本。更新前可先完成当前练习。
- 开发者发布修改时，应同时提高 `sw.js` 的 `VERSION`，并将全部文件作为同一批版本上传。缓存名包含注册作用域的哈希值，只清理相同作用域前缀的旧版本。
- 缓存解决页面和本地资源的离线访问，**不代表语音识别可以离线工作**，也不会替用户缓存外部语音服务。

## 语音朗读与跟读反馈

### 本地朗读 TTS

只选择浏览器报告 `localService === true` 的英语语音。找不到本地英语语音时，应用给出安装提示，不回退到云端语音。可在 iPhone 系统的“辅助功能”下查找“朗读与语音”或“朗读内容”及其“声音”，安装英语语音后返回，再次点击朗读。设置名称随系统版本变化；系统已下载语音是否向浏览器开放，也由系统和浏览器决定。

自动选择优先本地美式英语；依据声音名称及voiceURI中的Premium、Enhanced、Neural或Natural标记排序，同等级优先Samantha及Apple系统声音。这些名称只用于偏好判断，不保证语音质量或神经语音可用。已手动选择的可用语音仍优先保留。默认语速为0.75，固定音高为1.0；滑块仍支持0.6—1.0，并保留之前手动保存的语速。每次朗读会在控制台打印语音名称、语言、语速和音高，不打印学习文本。

语音列表可能延迟出现，等待片刻后再次点击；首次播放必须由用户点击触发。无法出声时检查音量、音频输出和当前录音状态。`localService` 的含义见 [MDN语音本地服务属性](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesisVoice/localService)。

### 语音识别 ASR

跟读使用浏览器或系统提供的 Speech Recognition。是否可用、是否需要联网、权限与处理位置取决于设备、浏览器和系统服务；部分浏览器会把音频交给远端识别服务。本应用没有自己的语音服务器，也不能因此保证音频始终不离开设备。使用前查看页面说明，按意愿授权麦克风；不愿使用系统识别服务时，可改用手动输入。

反馈比较的是识别文字与目标句、关键词的匹配情况，属于练习参考，**不是音素评分、口音评级或专业发音诊断**。识别错字不一定是发音错误；没有听到、网络中断或服务不可用时，不应把结果当作语言能力结论。Safari 的语音识别由系统服务支持，相关设置可能影响可用性。依据：[MDN语音识别](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition)、[WebKit语音API说明](https://webkit.org/blog/11648/new-webkit-features-in-safari-14-1/#web-speech-api)。

单次文字对比最多300个英文词；长篇内容应在课程JSON中分成多个学习条目。识别结束后自动对比一次，手动修改文字后可再次提交。点击其他页面或切换目标会取消本次录音；权限失败时保留原先输入。

## 导入课程与备份

课程采用本地 JSON 文件，可先参考 `demo.json` 和 `course.schema.json`。基本结构为：

```json
{
  "pack_name": "我的外贸英语",
  "version": "2026.11",
  "modules": [
    {
      "module": "产品介绍",
      "items": [
        {
          "en": "Which product category are you interested in?",
          "zh": "您对哪类产品感兴趣？"
        }
      ]
    }
  ]
}
```

- `en` 与 `zh` 必填；可选字段包括 `phonetic`、`example`、`example_zh`、`role`、`keywords`、`reference`。不提供ID时会生成稳定ID；同内容再次导入保持可识别性。
- 客户项的 `reference` 是可选的英文参考回答，不用于填写来源或备注；省略时使用紧随其后的 `You.en`。对应的中文参考说明使用该 `You` 项的 `zh`。
- 情景模块的 `scene` 为 `exhibition`、`negotiation` 或 `complaint`；使用交替的 `Client` / `You` 项。客户项的 `keywords` 对应学习者可能说出的回答，下一条 `You` 项作为参考回答。
- 文件校验通过后才写入；请按提示修正未知字段、空内容或格式错误。普通课程文件上限5 MiB；带 `format` 标识的完整学习备份上限50 MiB，并须通过备份结构校验。课程数量与条目还有格式规定的上限。选择文件或检查粘贴内容后，先核对预览中的覆盖／合并提示，再点击“确认导入”。
- 恢复备份采用**合并**：相同课程ID使用备份中的课程内容覆盖；相同进度项保留更新时间较新的记录；相同弱项词的次数取较大值，合并相关上下文；备份中提供的设置覆盖相同设置项。恢复前可再导出一次当前数据。
- 导出备份后，将下载的JSON文件保存到“文件”或其他自己管理的位置。导出也受对应可恢复大小上限约束；超限时会提示，避免生成无法重新导入的文件。备份可包含练习转写和学习记录，请按自身需要保存与分享。

数据不会自动跨设备或跨浏览器同步。同一设备、同一浏览器和同一 origin（协议、主机、端口）下才使用对应的存储；例如 `localhost:8000`、`localhost:8001`、`127.0.0.1:8000` 与正式HTTPS域名互不共享。Safari 与主屏幕网页App的存储表现还可能因系统版本及使用方式不同，迁移时以导出／恢复备份为准。

清理网站数据、重置设备、浏览器存储回收或系统空间压力都可能导致本地记录丢失，安装到主屏幕也不等于永久备份。请定期导出。WebKit对存储额度和回收的说明见 [WebKit存储策略](https://webkit.org/blog/14403/updates-to-storage-policy/)。

## 新版例句、查词与生词本

- 新装应用会自动添加“行业词汇·五句进阶”。原来只装有Demo的设备首次升级时也会选中这个新包，原学习记录保留；有自定义课程时保留原课程选择。
- 每条记录包含`word`、`zh`和5个`{en,zh}`例句，前两句基础、中间两句进阶、最后一句较复杂。近义表达分别建卡；释义说明近义但不可完全互换的边界。选择该课程包后，可以搜索英文、中文意思或例句中的客户表达。
- 点击“显示释义”展开五句例句。每句可单独朗读或送入跟读页；点击其中任意英文单词打开浮窗，查看释义、音标并发音或收藏。
- 长按单词超过500毫秒直接加入生词本。滑动、取消触控或切换页面会取消未完成的长按，避免滚动时误收藏。支持`navigator.vibrate`的设备会尝试短震动；iPhone Safari通常不提供该接口，仍会显示收藏提示。
- 底部“生词本”可搜索、筛选待复习／已熟悉、展开释义及原句、跟读和移除。它与跟读自动形成的弱项词库分别保存。
- 查词使用已缓存的本地词典，运行时不调用外部查词API。基础释义与音标子集来自开放许可ECDICT，并加入医疗器械语境释义；来源和完整许可见`THIRD_PARTY_NOTICES.txt`。词形回到原形时会明确标注；课程外新词、型号或少数缩写未收录时明确提示，不编造释义或音标，仍可收藏并回看原句。
- IndexedDB升级到v2会保留原课程、进度、收藏和设置。新备份使用`format_version: 2`并包含`vocabulary`；旧v1备份仍可恢复，且不会清空已有生词。

### 文件替换说明

直接使用线上App只需重新打开并接受“更新并重新打开”，无需手工导入。自行静态托管时，请用完整源码ZIP一起替换文件；本次除`app.js`和`courses_expanded.json`外，还更新了`index.html`、`styles.css`、`db.js`、`import.js`、`course.schema.json`、`sw.js`，并增加`lexicon.json`与许可文件，不能只替换单个脚本。保留已有网站数据，不要清空IndexedDB。

`courses_expanded.json`是用户要求的纯词条数组，也可通过“数据 → 选择JSON文件”直接导入。普通课程包继续支持单个`example`／`example_zh`；新增`examples: [{en,zh}, ...]`可存多句。内置扩充包的课程版本在`import.js`的`expandedToPack`中维护；将来升级内置词库时应同时提高该版本与`sw.js`的缓存版本，匹配学习项ID的进度会保留。
